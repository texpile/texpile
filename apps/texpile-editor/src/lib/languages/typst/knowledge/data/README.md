# data

What Texpile knows about Typst's standard library (`std.json`, Typst 0.14.2) and the Typst Universe packages it
bundles (`packages/<namespace>/<name>/<version>.json`, listed in `index.json`), in the format of
`package-scan/typst/SPEC.md` in texpile-tools. Only `knowledge/` reads this folder.

`package-scan/typst/` in texpile-tools generates it (see its README). Regenerate it there to change it.
