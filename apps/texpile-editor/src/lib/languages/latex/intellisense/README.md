Completion, hover, argument hints, live checks, folding, rename and go-to-definition for LaTeX in CodeMirror. What they know about commands, environments, keys and options comes from Texpile's package data, read through `languages/latex/knowledge/`: the kernel, the class and the packages a document loads, with what each of them loads in turn. Commands and environments of common packages the document does not load come after them, and accepting one adds the `\usepackage`. The forms such as `\left( ... \right)` (`data/macroForms.ts`) come from LaTeX Workshop's data; licenses and provenance are in `data/VENDORED-LICENSES.md`.
