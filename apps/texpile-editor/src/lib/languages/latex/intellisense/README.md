Most of what's in this folder is heavily inspired by the [LaTeX Workshop](https://github.com/James-Yu/LaTeX-Workshop) VS Code extension's IntelliSense (completion, hover, folding, go-to-definition), reimplemented for CodeMirror. Commands and environments come from Texpile's own package files (`data/packages/`, in LaTeX Workshop's format, see `data/packages/README.md`): the kernel's, and those of the class, packages and libraries the project loads, with what each of them loads in turn (`packages/`). Commands and environments of common packages the project does not load come after them, and accepting one offers the `\usepackage`. LaTeX Workshop's vendored data supplies the forms such as `\left( ... \right)` (`data/macroForms.ts`), the package/class name lists, at-suggestions, and bib entry types. Licenses and provenance: `data/VENDORED-LICENSES.md`; credit also lives in the root README's Acknowledgements.
