# Paste and drop

Bring in content from other apps without retyping it.

## Paste into the editor

| You paste                                 | You get                                                                           |
| ----------------------------------------- | --------------------------------------------------------------------------------- |
| Text from Word, Google Docs or a web page | Headings, lists, tables, links, bold and italic. Fonts and colors are dropped.    |
| A range from Excel or Google Sheets       | A table.                                                                          |
| An answer from an AI chat, in Markdown    | Its headings, lists, tables, links and math.                                      |
| A screenshot or other picture             | An image, saved in an `images` folder next to the file. In the source editor too. |
| LaTeX or Typst source                     | The document it describes.                                                        |

Ctrl Shift V (Cmd Shift V on macOS) pastes plain text.

## Drop files into the project

- Drag files or whole folders from your file manager onto the file tree to copy them into the project. Drop onto a folder to put them there.
- Or copy files in your file manager, click the file tree, and press Ctrl V.
- Drag a picture onto the editor to insert it.
