# LaTeX on Windows

Texpile can install TeX Live for you. See [From Texpile](README.md#from-texpile-recommended). To install a distribution yourself, read on.

Run [install-tl-windows.exe](https://mirror.ctan.org/systems/texlive/tlnet/install-tl-windows.exe) (recommended) from CTAN for TeX Live, or install [MiKTeX](https://miktex.org/download). Restart Texpile if it is open.

You only need one of the distros above. In the rare case where you have multiple TeX distributions installed, you can pick one with the **LaTeX** picker in Preferences › Compiler.
