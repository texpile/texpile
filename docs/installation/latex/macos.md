# LaTeX on macOS

Install [MacTeX](https://www.tug.org/mactex/mactex-download.html). No setup afterward.

BasicTeX is a smaller download but can lack programs Texpile uses, such as `latexindent` or `biber`. Add them with `tlmgr`.
