# Typst on Linux

Install tinymist with its installer script:

```bash
curl -LsSf https://github.com/Myriad-Dreamin/tinymist/releases/latest/download/tinymist-installer.sh | sh
```

Or `brew install tinymist`. Restart Texpile if it is open.
