# Typst on macOS

```bash
brew install tinymist
```

Without Homebrew, use the installer script:

```bash
curl -LsSf https://github.com/Myriad-Dreamin/tinymist/releases/latest/download/tinymist-installer.sh | sh
```

Restart Texpile if it is open.
