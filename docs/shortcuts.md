# Keyboard shortcuts

The combinations below are for Windows and Linux. On macOS, use Cmd wherever a table says Ctrl. The same list is in the app under Edit › Keyboard Shortcuts.

## The app

| Shortcut       | Action                           |
| -------------- | -------------------------------- |
| Ctrl S         | Save                             |
| Ctrl K         | Command Palette                  |
| Ctrl T         | Go to File                       |
| Ctrl W         | Close the tab                    |
| Ctrl Shift T   | Reopen the Last Closed Tab       |
| Ctrl F         | Find in this document            |
| Ctrl Shift F   | Find in every file in the folder |
| Ctrl Shift N   | New window                       |
| Ctrl Alt Enter | Start or stop a compile          |
| F8             | Next spelling problem            |
| Shift F8       | Previous spelling problem        |
| Ctrl Shift V   | Paste without formatting         |

## Visual editor

Each key maps to the markup you would have typed.

| Shortcut       | Action                |
| -------------- | --------------------- |
| Ctrl B         | Bold                  |
| Ctrl I         | Italic                |
| Ctrl U         | Underline             |
| Ctrl \`        | Inline Code           |
| Ctrl .         | Superscript           |
| Ctrl ,         | Subscript             |
| Ctrl Shift 1…3 | Heading levels 1 to 3 |
| Ctrl M         | Inline Math           |
| Ctrl Shift M   | Display Math          |

## Source editor

| Shortcut       | Action                           |
| -------------- | -------------------------------- |
| Ctrl Alt ↑ / ↓ | Add a cursor above or below      |
| Ctrl D         | Select the next occurrence       |
| Ctrl Space     | Open Suggestions                 |
| F12            | Go to Definition (or Ctrl+Click) |
| Alt Enter      | Quick Fixes (Typst)              |
| Esc            | Hide the math preview            |

Vim and Emacs keybindings for the source editor are a setting. See [Preferences](preferences.md).
