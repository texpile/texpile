# Smart selection

Two ways to work with a block as a unit instead of the text inside it.

| Where to find it | Path                                  | Note                                                                                       |
| ---------------- | ------------------------------------- | ------------------------------------------------------------------------------------------ |
| Toolbar          | The dashed-square icon in the toolbar | Select parent block. Click again to select its parent, and again, walking up the document. |

## Select parent block

With your cursor anywhere in a block, click the toolbar's Select parent block button to select the whole thing (a paragraph, an equation, a table). Click it again and the selection grows to that block's parent, and again for its parent, one level at a time.

## In an equation

The math toolbar has the same idea, scoped to math: a Select equation block button selects the whole equation you are editing, in one click.

## The block handle

Hover any block and a handle appears in the left margin. Drag it to move the block, click + to insert a new block below, or click the trash icon to delete it. No selection is needed first.
