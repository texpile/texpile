# Terminal

A command line in your project folder, under **Terminal** in the bottom panel. Desktop app only.

Layout › Bottom Panel shows the panel. Command palette › Show Terminal opens it on a terminal, and Command palette › New Terminal adds another.

- Compiles run in a separate terminal tab named **Compile**. **Stop** stops only the compile.
- The terminal is your computer's usual shell, and it finds the programs in the folders under **Other folders** in Preferences › [Programs & Compiler](toolchain.md).
- Opening another folder closes the old terminals.

Copy with `Ctrl Shift C` and paste with `Ctrl Shift V` (`Cmd C` and `Cmd V` on macOS). Right-click copies the selection, or pastes when nothing is selected.
