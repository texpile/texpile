# Integrations

Other programs Texpile can talk to on your computer. Each is optional, and each has its own setting in Preferences.

- [Zotero](zotero.md): Pick citations from your Zotero library and add them to your bibliography.
- [AI assistants (MCP)](mcp.md): Let Claude Code or Codex read your editor state and drive the app, on your computer.
- [Agent tab](agent-panel.md): Ask an agent on your computer to edit the open folder, from the bottom panel.
