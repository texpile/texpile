# Integrations

Other programs Texpile can talk to on your computer. Both are optional, and each has its own switch in Preferences.

- [Zotero](zotero.md): Pick citations from your Zotero library and add them to your bibliography.
- [AI assistants (MCP)](mcp.md): Let Claude Code or Codex read your editor state and drive the app, on your computer.
