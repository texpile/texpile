# Markdown

A .md file opens in the same visual and source editors. There is no compile step and no PDF: the visual editor is the preview, and the file is saved back as plain Markdown.

| Where to find it | Path              | Note |
| ---------------- | ----------------- | ---- |
| In the editor    | Open any .md file |      |

![A Markdown file in the visual editor, with the heading levels rendered and the outline in the sidebar](../landing/src/lib/assets/showcase/app/markdown-visual.png 'A Markdown file in the visual editor, with the heading levels rendered and the outline in the sidebar')

## What differs

- Strikethrough and task lists have toolbar buttons of their own.
- Raw HTML, and anything else the editor cannot show, stays in place as a code chip. YAML front matter is edited in source mode.
- Completion in source mode covers file paths in links and images. The @ picker and Zotero are not offered.
