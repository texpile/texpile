# Typing and selecting

A few things the visual editor does as you type. Backspace straight after one undoes it.

## Quotes and dashes

In LaTeX and Typst:

| You type   | You get      |
| ---------- | ------------ |
| `"` or `'` | Curly quotes |
| `--`       | En dash (–)  |
| `---`      | Em dash (—)  |
| `...`      | Ellipsis (…) |

## Tab

In a table cell, Tab moves to the next cell. In a list, it indents the item. Shift Tab goes back.

In a LaTeX paragraph, Tab changes whether its first line is indented.

## Select a whole block

Ctrl-click (Cmd-click on macOS) a paragraph, an equation, a table or any other block to select all of it. Ctrl-click again to select the block around it, such as the whole list. The **Select block** button at the right of the toolbar does the same for the block the cursor is in.

Ctrl A in a table cell or a caption selects just that field. Press it again for the whole document.

## In an equation

Press Tab to find a symbol by its name or by what it means, such as `not eq` or `arrow right`. Enter inserts it.

## Delete a figure or an equation

Next to a figure, the first Backspace selects it and the second deletes it. An empty equation turns red first, then goes.
