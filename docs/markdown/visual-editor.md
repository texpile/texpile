# Visual editor

Edit the file as formatted text. Texpile writes the Markdown, and keeps the parts you do not touch as you wrote them.

Things that work differently from a word processor:

- An image's caption is saved as its title: `![alt](path "caption")`.
- A code block's settings icon sets its language.
- Tables always have a header row.
- Front matter at the top of the file is kept. Edit it in the source editor.
- Files over 800 KB open in the source editor.

## Typing shortcuts

At the start of a line, type the marker and a space.

| You type        | You get         |
| --------------- | --------------- |
| `#` to `######` | Heading 1 to 6  |
| `-` or `*`      | Bullet list     |
| `1.`            | Numbered list   |
| `>`             | Block quote     |
| ` ``` `         | Code block      |
| `---`           | Horizontal rule |

## Keyboard shortcuts

On macOS, use Cmd for Ctrl.

| Shortcut     | Action           |
| ------------ | ---------------- |
| Ctrl Alt 1   | Heading 1        |
| Ctrl Alt 2   | Heading 2        |
| Ctrl Alt 3   | Heading 3        |
| Ctrl Shift X | Strikethrough    |
| Ctrl `       | Inline code      |
| Ctrl Shift ` | Code block       |
| Ctrl Shift B | Quote            |
| Ctrl M       | Inline equation  |
| Ctrl Shift M | Display equation |
