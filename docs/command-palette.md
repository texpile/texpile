# Command palette

A place to search the editor's actions and your files. Press Ctrl K (Cmd K on macOS), or click the window title.

![The command palette open on the Compile and View commands](../landing/src/lib/assets/showcase/docs/app/command-palette-open.png)

Ctrl T (Cmd T) searches files only.
